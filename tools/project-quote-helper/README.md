# 接案報價小幫手

## 工具用途

協助個人接案者、小型工程團隊與職人在正式報價前整理材料、人力與必要支出，快速檢查報價是否完整。

本工具不是市場行情工具，不替使用者決定應收價格，也不提供正式會計、稅務或獲利判斷。

## 介面方向

正式工具已改為「職人工程工作單」視覺：工程資料、主要支出、其他可能支出、報價檢查結果、支出明細與待確認清單呈現在同一張施工估價草稿中。

桌面版採大型工作單版型；手機版採同頁完整工作單，區塊可展開與收合：

1. 工程資料
2. 主要支出
3. 其他支出與工程特徵
4. 工程特徵
5. 報價檢查結果

手機版不強迫逐步翻頁；使用者可在同一頁完成所有欄位、快速跳到結果。頁面狀態不寫入 localStorage，重新整理後會清空。

## 計算公式

人力費用 = 施工人數 × 預估工作天數 × 每人每日人力成本

預估總支出 = 人力費用 + 材料費 + 外包費 + 停車費 + 耗材費 + 餐費 + 其他必要支出 + 拆除費 + 清運費 + 高處作業／吊車／鷹架費 + 設備租用費 + 交通／車馬費 + 住宿費 + 預留材料費 + 保固／回訪預留費 + 防護／清潔費

報價與支出差額 = 預計報價金額 - 預估總支出

內部風險判斷會保留差額與報價的相對關係計算，但結果畫面不顯示比例數字。

## 提醒規則

提醒規則集中於 `rules.js`，分為：

- 必要資料提醒
- 情境缺漏提醒
- 報價風險提醒

比例判斷僅為第一版測試規則，不代表業界標準。正式畫面以白話章戳、報價檢查尺與待確認清單呈現，不顯示差額比例。

## 第一版限制

- 不提供市場行情
- 不提供正式會計或稅務判斷
- 不建立正式報價單
- 不輸出 PDF
- 不保存案件資料
- 不上傳照片
- 不串接 API

## 隱私原則

工具只在瀏覽器本機計算，不保存表單內容，不寫入 localStorage，不傳送金額、工程資料、客戶資料或摘要全文。

analytics 僅允許記錄：tool_id、pack_id、action、page、project_type、risk_level。
